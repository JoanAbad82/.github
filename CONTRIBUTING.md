# Contributing

Contributions are welcome when they are bounded, reviewable, and relevant to the repository.

Before contributing:

1. Read the repository README, SECURITY.md, and any repository-local contributor or agent instructions.
2. Search existing issues and pull requests before opening duplicates.
3. Keep changes focused. Separate unrelated changes.
4. Include tests, reproduction steps, evidence, or validation output when applicable.
5. Do not include secrets, credentials, private datasets, or third-party confidential material.

For bug reports, include the smallest reproducible case you can provide. For proposals, explain the expected benefit, constraints, and how the change could be falsified or validated.

Repository-local instructions override this account-wide default.
